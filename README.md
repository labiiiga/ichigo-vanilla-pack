# Ichigo: vanilla fan pack (Java 26.2)

แพ็ก Bleach สำหรับ Java 26.2: ไม่ต้องติดตั้งมอดฝั่งผู้เล่น เพื่อนยอมรับ resource pack ตอนเข้าเซิร์ฟ
โมเดลและเสียงเอฟเฟกต์เป็นงานสร้างใหม่สำหรับแพ็กนี้

## เล่น

เข้าเซิร์ฟเวอร์แล้วกดยอมรับ resource pack จากนั้นพิมพ์:

`/trigger ichigo set 8`

คลิกชื่อร่างในแชต หรือใช้ `/trigger ichigo set <เลข>`:

| เลข | ร่าง | อุปกรณ์ |
|---|---|---|
| 1 | Shikai | Zangetsu / ชุดยมทูต / ออร่าฟ้า |
| 2 | Bankai | Tensa Zangetsu / เสื้อคลุมดำ / ออร่าแดงดำ |
| 3 | Hollow (60 วินาที) | หน้ากากกับผมทรงแหลม / ออร่าแดง |
| 4 | Vasto Lorde (30 วินาที) | หน้ากากมีเขา / ออร่าส้ม / Cero |
| 5 | True Shikai | ดาบคู่ / ออร่าฟ้า |
| 6 | Mugetsu (20 วินาที) | ผมและผ้าพันหน้า 3D / ชุดพันแผล |
| 7 | คืนชุดเดิม | เกราะเดิมถูกเก็บไว้ในตัวเก็บอุปกรณ์แยกตามผู้เล่น |
| 8 | เมนู | ทุกคนใช้ได้โดยไม่ต้องเป็น OP |

เลือกดาบที่ได้รับขึ้นมาถือในมือหลักก่อนใช้ท่า:

- คลิกขวา: Getsuga Tensho (12 พลัง / คูลดาวน์ 1 วินาที)
- ย่อ + คลิกขวา: Shunpo (8 พลัง / คูลดาวน์ 0.8 วินาที)
- วิ่ง + คลิกขวา: Getsuga Jujisho; ร่าง Vasto ใช้ Cero (25 พลัง / 3 วินาที)
- อยู่กลางอากาศ + คลิกขวา: คลื่นไม้ตาย (60 พลัง / 45 วินาที)
- พลังวิญญาณสูงสุด 100 ฟื้น 2 ต่อวินาที

เซิร์ฟนี้เปิดสตามิน่าไม่จำกัดและไม่มีคูลดาวน์ไว้แล้ว ค่าด้านบนเป็นค่าปกติเมื่อปิดโหมดทดสอบ
ผู้ดูแลตั้งค่าได้ด้วย `scoreboard players set #unlimited ig.energy 1`
และ `scoreboard players set #nocd ig.cool 1` (ใช้ 0 เพื่อคืนค่าปกติ)

ท่าโจมตีเฉพาะรายชื่อมอนสเตอร์ในแท็ก `ichigo:targets` ไม่โดนผู้เล่น สัตว์เลี้ยง หรือบล็อก
Hollow/Vasto กลับ Bankai เมื่อหมดเวลา ส่วน Mugetsu คืนอุปกรณ์เดิม
ท่าไม่ได้เปลี่ยนกฎ PvP ปกติของเซิร์ฟเวอร์: การตีด้วยดาบยังเป็นการโจมตีปกติของเกม

## เอฟเฟกต์และการโจมตี

ตั้งแต่ v0.3.0 ดาบและคลื่น Getsuga, Jujisho, Cero, วงออร่า,
เงาร่างฟันดาบ, ทรงผม และชายเสื้อใช้โมเดลหลายชั้นที่สร้างและจัดฉากใน Blender
แสงวงแหวนกับอนุภาคเปลี่ยนสีตามร่าง มีเสียงชาร์จ ปลดปล่อย ฟัน วาร์ป และปะทะที่สร้างใหม่
ผู้เล่นและเพื่อนรอบ ๆ จะเห็นการเหวี่ยงแขนจริงของ Minecraft ตอนปล่อยท่า
ข้อจำกัด vanilla คือขยับกระดูกทั้งตัวแบบอนิเมะไม่ได้ เสื้อคลุมจึงเป็นชิ้นเกราะตกแต่ง
เงาตัวละครช่วงโจมตีเป็นภาพแทนที่ลบตัวเองหลังจบ ไม่มีการเปลี่ยนรูปร่างโมเดลผู้เล่นหลัก
ระบบเปลี่ยนร่างให้ดาบเข้า inventory จึงควรเหลือช่องว่าง 2 ช่อง
อย่าแก้ไข/ถอดชุดขณะเปลี่ยนร่างด้วย creative หรือคำสั่งของมอดอื่น

ตัวเก็บอุปกรณ์เป็น armor stand มองไม่เห็นใน overworld ที่ 0,-61,0
มี forceload 1 chunk เพื่อคืนเกราะได้แม้ผู้เล่นเปลี่ยนมิติ
ปิดร่างของทุกคนก่อนเอา datapack ออก เพื่อให้ชุดเดิมคืนครบ

## ติดตั้งบนเซิร์ฟเวอร์อื่น

แตก datapack ZIP ไปยัง `<world>/datapacks/ichigo` แล้ว `/reload`
โฮสต์ resource pack ZIP บน URL HTTPS ที่โหลดไฟล์โดยตรง และตั้งใน `server.properties`:

```properties
resource-pack=https://github.com/labiiiga/ichigo-vanilla-pack/releases/download/v0.3.0/Ichigo-26.2-resourcepack.zip
resource-pack-sha1=<ค่าจาก dist/resourcepack.sha1>
require-resource-pack=true
resource-pack-prompt={"text":"Ichigo: ดาวน์โหลดดาบ 3D ชุดและเอฟเฟกต์เพื่อเล่นบนเซิร์ฟนี้","color":"aqua"}
```

รีสตาร์ตเซิร์ฟเวอร์ให้การตั้งค่า resource pack มีผล
ผู้เล่นเข้าเซิร์ฟแล้วกดยอมรับได้โดยไม่ต้องติดตั้ง Fabric/Forge

## สร้างแพ็ก

Python 3.12 + Pillow + FFmpeg:

```text
py -3.12 build.py
py -3.12 verify.py
```

ไฟล์ Blender ที่แก้ไขต่อได้: `art/getsuga.blend` (Blender 5.2.2)
ต้นฉบับสร้างด้วย `art/create_getsuga.py` ใน Blender; bake ใหม่ด้วย:

```text
blender -b art/getsuga.blend --python art/bake_getsuga.py
py -3.12 build.py
py -3.12 verify.py
py -3.12 art/preview_getsuga.py
```

เฟรมที่ bake แล้วอยู่ใน `art/frames` จึง build แพ็กได้โดยไม่ต้องเปิด Blender
`dist/getsuga-preview.png` และ GIF เป็นภาพจาก Blender; `dist/cinematic-arsenal.png`
เป็นพรีวิวฉาก Blender ของโมเดล VFX ที่แพ็กใช้งานจริง

`dist/asset-preview.png` เป็นภาพพรีวิว geometry ที่เรนเดอร์นอกเกม ไม่ใช่ภาพจาก Minecraft
การตรวจอัตโนมัติครอบคลุม JSON, geometry bounds, ลิงก์เท็กซ์เจอร์/อุปกรณ์ และ ZIP integrity
ตรวจแพ็กบน Minecraft 26.2 แล้ว ทั้งหน้ากดยอมรับ แปลงครบหกร่าง คืนเกราะเดิม
ทดสอบท่า 18 ครั้ง ดาเมจมอนสเตอร์ วงแหวน ออร่าหมดอายุ และแยกเอฟเฟกต์ผู้เล่นหลายคน

โปรเจกต์แฟนเมด ไม่ได้เกี่ยวข้องกับผู้ถือลิขสิทธิ์ Bleach หรือ Mojang
